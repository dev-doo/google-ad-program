# 티스토리 자동 채우기 확장 — 설치 방법

티스토리는 **오픈 API가 2024년 2월에 완전히 종료**되어, 외부 프로그램이 글을 올릴 수 있는
공식 통로가 없습니다. 그래서 이 확장이 티스토리 글쓰기 **화면을 직접 조작**해서 채웁니다.

> ⚠ 남의 화면에 의존하는 방식이라 **티스토리가 편집기를 바꾸면 깨집니다.**
> 깨지면 화면 오른쪽 아래에 "본문 칸을 찾지 못했습니다" 라고 뜹니다.
> 그때는 글이 클립보드에 복사돼 있으니 Ctrl+V 로 붙여넣으시면 됩니다.

## 설치 (1분)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 `extension` 폴더를 선택

설치되면 글 도우미의 `게시하기`가 자동으로 이 확장을 씁니다.
(확장이 없으면 예전처럼 복사 + 창 열기로 동작합니다. 따로 설정할 것 없습니다.)

## 쓰는 법

1. 글 도우미 **설정**에 블로그 주소를 넣습니다 — 예: `myblog.tistory.com`
2. 글을 다 쓰고 **게시하기**
3. 티스토리 글쓰기 창이 열리고 **제목과 본문이 자동으로 채워집니다**
   - 진입할 때 "저장된 글이 있습니다. 이어서 작성하시겠습니까?" 확인창이 뜨면
     **먼저 처리**해 주세요. 그대로 두면 채우기가 기다리다 멈춥니다.
4. 오른쪽 아래 패널에 **"저장될 본문 N자 확인"** 이 떴는지 봅니다
5. 내용을 확인하고 **[발행 창 열기]**

마지막 발행은 확인 후 누르도록 남겨 두었습니다. 잘못된 글이 그대로 공개되는 것을 막기
위해서입니다. 대표 이미지도 이 화면에서 올리셔야 합니다.

> 티스토리 발행 설정은 **기본값이 비공개**입니다. 공개하려면 발행 창에서 직접 바꾸세요.
> (계정당 하루 공개 발행 15개 한도가 있다는 보고가 있습니다.)

## ⚠ 반드시 "기본모드" 에서 쓰세요

티스토리 글쓰기는 작성 모드가 **기본 / 마크다운 / HTML** 세 가지입니다.
이 확장은 **기본모드**에서만 글을 채웁니다. 다른 모드에서는 넣어도 **빈 글로 발행됩니다**
(편집기 내부 값이 실제 저장되는 값에 반영되지 않습니다). 그래서 마크다운·HTML 모드를
감지하면 채우지 않고, 기본모드로 바꾸라고 안내합니다.

> 모드는 글쓰기 화면 오른쪽 위 `⋯` 에서 바꿉니다. 바꿀 때
> "서식이 유지되지 않을 수 있습니다" 확인창이 뜨면 확인을 누르세요.

## 무엇이 들어 있나

```
manifest.json     확장 설정
bridge.js         글 도우미 페이지 ↔ 확장 연결 (window.postMessage 를 받아 전달)
background.js     글을 잠깐 보관하고 티스토리 글쓰기 탭을 연다
tistory.js        제목·본문 칸을 찾아 채운다 (격리된 세계)
tistory-main.js   페이지와 같은 세계에서 돌며 TinyMCE 를 만진다
```

### 왜 스크립트가 둘인가
보통의 확장 스크립트는 페이지와 **격리된 세계**에서 돌아 페이지의 `window.tinymce` 에
닿지 못합니다. `tistory-main.js` 는 `"world": "MAIN"` 으로 페이지와 같은 세계에서 돌고,
둘은 CustomEvent 로만 이야기합니다. (`<script>` 태그를 심는 우회법도 있지만 티스토리의
CSP 가 막을 수 있어 쓰지 않았습니다. Chrome 111 이상 필요.)

### 조용히 실패하지 않게 한 것
**가장 위험한 실패는 "채운 것처럼 보이지만 빈 글이 발행되는 것"** 입니다.
티스토리가 서버로 보내는 값은 화면에 보이는 편집기가 아니라 숨은
`textarea#editor-tistory` 이고, TinyMCE 에 `setContent()` 만 하면 이 칸이 비어 있습니다.
그래서 이 확장은 `setContent()` 뒤에 **`save()` 로 동기화하고, 그 칸의 글자 수를 세어
0 이면 실패로 보고**합니다. 패널에 "저장될 본문 N자 확인" 이라고 나오면 통과한 것입니다.

`tistory.js` 는 선택자를 하나로 못 박지 않고 **여러 방법으로 편집기를 찾습니다**
(TinyMCE API, iframe 안쪽, contenteditable, 제목 placeholder 등). 티스토리가 화면을
조금 바꿔도 버티게 하려는 것이고, 그래도 못 찾으면 화면에 무엇을 못 찾았는지 알립니다.
실패하면 글을 버리지 않고 되돌려 두므로, **새로고침(F5)하면 한 번 더 시도**합니다.
