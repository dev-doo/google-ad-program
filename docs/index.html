✦ 티스토리 글 도우미

1. 글 만들기

체크하면 [내 경험] 같은 자리를 일부러 비워 둡니다. 내 이야기가 들어간 글이 저품질을 피하는 데 유리합니다.

2. 링크 버튼

넣고 싶은 위치를 글에서 한 번 클릭한 뒤 아래를 채우고 넣으세요. 개수 제한은 없습니다. 넣을 때마다 그 아래에 차곡차곡 들어갑니다.

"제휴 링크 포함" 안내 문구는 글 끝에 자동으로 붙습니다.
